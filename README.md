# PROYECTO-KULA

Página web para estudiantes universitarios. Les permite subir material de estudio previamente utilizado para su disponibilidad a próximos estudiantes que cursen los mismos ramos en el futuro. 

El propósito de este proyecto es democratizar el contenido útil para el estudio a estudiantes que estén cursando cualquier ramo por primera vez. Bajo mi visión, el material disponible para dichos estudiantes es muestra que los intercambios se basan en el valor de la cooperación y solidaridad de estudiantes que ya cursaron con éxito sus ramos. No siempre bajo el velo de lo instrumental, en su denotacion mas negativa. Quiero que la barrera respecto al acceso de informacion de calidad se desplome, permitiendo a cualquier estudiante acceder a apuntes, pruebas y cualquier material que permita la realizacion de sus cursos, reduciendo la incertidumbre sobre el "desde donde empezar" y el "como proseguir". Haciendo que desde el minuto 0, tenga toda las directrices necesarias para el desarrollo de su curso.
